# VideoRecorder

适用于 Windows 的屏幕录制工具，支持全屏/区域录制、系统声音和麦克风采集。

## 功能特性

- **屏幕录制** — 全屏、区域、窗口三种模式
- **系统声音采集** — 基于 WASAPI Loopback，无需虚拟声卡
- **麦克风采集** — 支持系统默认和指定麦克风设备
- **摄像头画中画** — 录制时叠加摄像头画面
- **硬件编码** — 支持 Intel QSV / NVIDIA NVENC / AMD AMF 硬编加速
- **分段录制** — 按设定时间自动分段保存
- **定时停止** — 设定录制时长后自动停止
- **系统托盘** — 支持最小化到托盘录制

## 系统要求

- Windows 10 1803 及以上
- 64 位操作系统
